# 🚀 Space-Dodge

A simple 2D survival game built with **Python** and **Pygame** where the player controls a spaceship and dodges incoming obstacles for as long as possible. The objective is to survive, improve your reaction time, and achieve the highest score.

## 🎮 Features

* Smooth 2D gameplay
* Keyboard-controlled spaceship
* Randomly spawning obstacles
* Score tracking based on survival time
* Simple and beginner-friendly game mechanics

## 🛠️ Technologies Used

* Python 3
* Pygame

## 📦 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Dheeraj-kanna/Space-Dodge.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Space-Dodge
   ```

3. Install Pygame:

   ```bash
   pip install pygame
   ```

4. Run the game:

   ```bash
   python main.py
   ```

## 🎯 Controls

* **← / A** – Move Left
* **→ / D** – Move Right
* **Esc** – Exit the game (if implemented)
